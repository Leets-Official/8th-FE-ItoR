# Code Style

React, TypeScript, Tailwind CSS 코드를 작성하거나 수정할 때 적용합니다.

## 기본 원칙

- 기존 ESLint, TypeScript, Prettier 설정을 코드 스타일의 기준으로 사용합니다.
- 단순하고 읽기 쉬운 구현을 우선하며 필요가 확인되지 않은 추상화를 만들지 않습니다.
- 같은 상태를 여러 곳에 저장하지 않고 계산 가능한 값은 렌더링 중에 계산합니다.
- 반복되는 조건과 스타일은 의미 있는 상수나 매핑으로 분리합니다.
- 함수가 길어지면 줄 수보다 책임 단위로 분리 여부를 판단합니다.

## React

- 함수형 컴포넌트와 Hooks를 사용합니다.
- 컴포넌트는 `function` 선언으로 작성합니다.
- 커스텀 Hook과 이름 있는 일반 함수도 `function` 선언으로 작성합니다.
- 콜백을 컴포넌트처럼 분리하거나 컴포넌트에 `use` 접두사를 붙이지 않습니다.
- props는 구조 분해로 받고 기본값은 매개변수에서 지정합니다.
- state는 실제 상호작용에 필요한 최소한만 둡니다.
- 파생 값 때문에 `useEffect`를 사용하지 않습니다.
- 이벤트로 처리할 수 있는 로직은 Effect로 옮기지 않습니다.
- Hook은 컴포넌트 최상위에서 조건 없이 호출합니다.
- React Compiler를 사용하므로 근거 없이 `memo`, `useMemo`, `useCallback`을 추가하지 않습니다.
- DOM 접근, 포커스, 파일 입력, 커서 위치처럼 렌더링과 무관한 값을 보존할 때만 `useRef`를 사용합니다.
- 목록 렌더링에는 항목을 안정적으로 식별하는 `key`를 사용합니다.
- 입력 컴포넌트는 controlled와 uncontrolled 사용 방식을 섞지 않습니다.

## TypeScript

- props, 함수 입력과 반환 값의 경계를 명확히 타입화합니다.
- 타입 추론이 충분한 지역 변수에는 중복 타입을 적지 않습니다.
- 문자열 상태와 variant는 가능한 값의 union으로 제한합니다.
- 타입 단언과 non-null assertion은 값의 안전성을 코드로 보장한 경우에만 사용합니다.
- `any`, 불필요한 enum, 동작 없는 wrapper 타입을 만들지 않습니다.
- 사용자 입력과 외부 데이터는 사용 전에 검증하거나 안전한 기본값을 적용합니다.

## Tailwind CSS

- 색상, 글꼴, 아이콘 크기, breakpoint는 기존 Tailwind 설정과 CSS 변수를 사용합니다.
- 이미 정의된 `text-*`, `gray-*`, `icon-*` 토큰을 임의의 값보다 우선합니다.
- 임의 값은 디자인 값이 토큰으로 존재하지 않고 해당 위치에만 필요한 경우에 사용합니다.
- 같은 임의 값이 반복되면 공통 토큰이나 스타일로 승격할지 검토합니다.
- class 순서는 `prettier-plugin-tailwindcss`에 맡기고 수동 규칙을 만들지 않습니다.
- 조건부 class가 복잡해지면 variant별 문자열 매핑으로 분리합니다.
- 전역 너비와 breakpoint를 개별 컴포넌트에서 중복 선언하지 않습니다.
- Figma의 `Hug`는 콘텐츠에 맞는 `w-fit` 또는 `h-fit`, `Fill`은 부모를 채우는
  `w-full` 또는 `h-full`로 해석하되 실제 레이아웃 문맥을 확인합니다.

## 접근성

- 클릭 동작에는 기본적으로 `button`을 사용하고 `type="button"`을 명시합니다.
- 입력 요소에는 연결된 `label` 또는 접근 가능한 이름을 제공합니다.
- 아이콘만 있는 버튼에는 `aria-label`을 제공합니다.
- 장식용 아이콘은 보조 기술에서 숨깁니다.
- 오류나 주의 문구는 상황에 맞는 `role`과 입력 요소의 연결 상태를 함께 고려합니다.
- `disabled`, focus, hover, active 상태는 의미와 디자인을 모두 반영합니다.
- 모달과 드로어는 열린 영역 안에 포커스를 유지하고 Escape 닫기와 이전 포커스 복원을 지원합니다.
- 드롭다운 메뉴는 키보드 방향키와 Escape로 이동하고 닫을 수 있어야 합니다.

## 성능

- 라우트 컴포넌트는 TanStack Router의 자동 코드 분할을 사용합니다.
- 루트 레이아웃의 조건부 모달·드로어처럼 라우트 밖의 큰 UI만 React `lazy`로 지연합니다.
- 반복 목록과 화면 아래 이미지는 `loading="lazy"`, `decoding="async"`를 적용합니다.
- 첫 화면의 주요 이미지만 `eager`와 높은 fetch priority를 사용합니다.
- 이미지의 표시 크기를 아는 경우 `width`와 `height` 속성을 함께 제공합니다.
- 공개 메인·회원가입 화면은 `pnpm audit:lighthouse`로 네 항목 모두 90점 이상인지 확인합니다.

## 검증

- 타입 오류와 린트 경고를 무시하거나 설정으로 숨기지 않습니다.
- UI 변경은 기본, hover, focus, active, disabled 상태를 필요한 범위에서 확인합니다.
- 반응형 변경은 1366px 최대 영역과 390px 이하 모바일 기준을 확인합니다.
